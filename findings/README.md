# findings — 실패 기록

spec §0: "값어치는 코드가 아니라 실패 기록". 밤이 드러낸 **하네스 자체의** 구멍을 파일 하나씩 남긴다. 지우지 않는다.
번호는 순서일 뿐이다 — 날짜는 본문의 메타데이터이고 식별자로 쓰지 않는다.

형식 (고정): **발견**(밤 ID · 로그 증거) / **증상** / **피해** / **원인** / **해소**(커밋) / **재발 방지**(테스트) / **가정 변경**(ASSUMPTIONS 행) / **일반화**

- 밤 SUMMARY의 "이상 징후"가 하네스 자체의 문제로 밝혀지면 여기에 쓴다. 대상 repo의 버그는 여기가 아니다 — 그건 도메인 것.
- 해소 없이도 쓴다(열린 발견). 해소되면 커밋 해시를 적는다.
- Phase 5의 "트레이스 → 실패 유형 분류"는 이 디렉토리가 쌓인 뒤 그것을 재료로 한다.
