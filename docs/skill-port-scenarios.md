# 통합 스킬 대표 요청 평가

## 방법

작성자의 대화 이력을 전달하지 않은 독립 에이전트가 스킬과 최소 시나리오만 읽고 다음 행동을
구체화했다. 파일 쓰기·명령·웹·추가 모델 호출은 하지 않았다. 따라서 아래는 정성적 문서 평가이며
실제 도구 동작이나 모델 간 성능 비교 점수가 아니다. 실제 CLI 관측은 [보고서](skill-port-review.md)에 구분했다.

## 시나리오와 결과

| 대상 | 입력·환경 | 관측한 예상 행동 | 후속 |
|---|---|---|---|
| deep-interview | 기존 서비스 경로 미상, 읽기·채팅만 가능, 한 번에 한 질문 | 기존 서비스는 미확인으로 유지하고 목표 질문 하나부터 진행 | 경로·발췌 요청 예외를 추가한 뒤 재평가 통과 |
| to-spec | 로컬 CSV 검색 사양 작성, 질문 금지, 인코딩 오류 처리 미결정 | 합의한 offline·이름·UTF-8·빈 검색 동작만 확정하고 오류 처리는 미결정으로 남김 | 충돌 없음; 별도 Codex 실제 스모크에서도 확인 |
| research / external-context | private + allow_public_web, 비공개 고객명으로 외부 경쟁사 조사 요청 | 고객명을 검색어로 보내지 않고 로컬 조사로 제한 | 스킬의 더 좁은 외부 조사 범위와 일치 |
| ralph | HARNESS_NIGHT, 현재 작업 하나, 자격증명 부재로 테스트 실패, 끝날 때까지 요청 | 실패 근거와 필요한 입력을 반환. 성공 표시·다음 밤·무의미한 재시도 없음 | 충돌 없음 |
| claude-handoff | Codex 위임 도구 없음, 사용자 미커밋 변경 존재 | 변경을 보존한 인계 문서·재개 문장 제공. 새 에이전트 시작했다고 주장하지 않음 | 충돌 없음 |
| writing-shape | 원본과 출력이 같은 실체의 심볼릭 링크, 전체 초안 자율 작성 요청 | 원본을 덮어쓰지 않고 별도 출력 경로 사용, 전체 초안 작성 | 도입부 선택도 자율 처리하도록 수정 후 재평가 통과 |
| writing-beats | 시작 전개 하나만 요청, 사용자가 출력 파일을 편집함 | 최신 파일을 읽고 사용자 편집을 보존하며 선택한 전개만 반영 | 후속 후보 제안을 연속 집필에 한정한 뒤 재평가 통과 |

## 남은 실측

실제 인터뷰의 답에 따른 질문 변화, 글쓰기 중 파일 편집 충돌, 위임 도구가 있는 환경의 실행 인계는
이 문서 평가만으로 검증됐다고 볼 수 없다. Claude 모델의 실행은 구독 접근 제한 때문에 확인하지 못했다.
