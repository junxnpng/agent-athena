# OMC·Matt 스킬 통합 이식 계획

## 목표

사용자가 지정한 원본 13종을 Codex·Claude에서 사용할 수 있는 하네스 스킬로 이식한다.
역할이 겹치는 절차는 정본을 공유하고 원본 이름은 호환 진입점으로 보존한다.

## 범위와 제약

- 인터뷰·조사·인계 통합, ralph·사양·에이전트 문서·글쓰기 세 종류 이식.
- 원본 고정 커밋·파일 해시·저작권을 보존한다.
- 기존 미커밋 훅 변경은 건드리지 않는다. 쓰기는 순차 수행한다.
- 스킬은 내용 지침만 제공한다. ID·로그·큐·예산·커밋은 기존 러너의 책임이다.
- 전역 설치·플러그인 갱신·커밋·push는 포함하지 않는다.

## 산출물과 검증

1. 원본 역할·의존성과 충돌을 감사하고 통합 대응표를 작성한다.
2. 공통 계약과 정본·호환 진입점, 출처 대장·사용 안내를 제공한다.
3. 독립 읽기 전용 리뷰와 대표 요청 시나리오로 경계·도구 부재·원본 보존을 점검한다.
4. 발견한 문제를 수정하고 형식·상대 링크·출처·네트워크 스킬 판별을 검증한다.
5. 가능하면 양쪽 CLI의 격리된 읽기 전용 스모크를 수행하고 실제 관측 범위만 보고한다.
6. scripts/check를 실행하고 완료·미검증 범위를 한국어 보고서에 남긴다.
