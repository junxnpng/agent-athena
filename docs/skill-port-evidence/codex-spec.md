**로컬 CSV 이름 검색 사양**

**문제·목표**
사용자가 네트워크 연결 없이 로컬 CSV의 항목을 이름으로 검색할 수 있도록 한다.

**기대 동작**

- 로컬 CSV를 UTF-8로 읽는다.
- 검색 대상은 이름이다.
- 빈 검색어를 입력하면 전체 목록을 표시한다.
- CSV 읽기와 검색은 오프라인에서 동작한다.
- 인코딩 오류 발생 시 동작은 미결정이며, 이 사양에서 확정하지 않는다.

**제약·비목표**
온라인 서비스 연동은 범위에서 제외한다. 이번 산출물은 채팅 사양이며, 파일 작성이나 구현 변경은 포함하지 않는다.

**성공 기준**

| 입력·조건 | 기대 결과 | 확인 방법 |
|---|---|---|
| 네트워크가 없는 환경에서 유효한 UTF-8 CSV 사용 | CSV 읽기와 이름 검색 가능 | 연결 차단 상태에서 동작 확인 |
| 이름이 서로 다른 항목으로 구성된 CSV에서 특정 이름 검색 | 합의될 이름 일치 규칙에 따른 결과 표시 | 검색 결과와 예상 항목 비교 |
| 유효한 CSV에서 빈 검색어 입력 | 전체 목록 표시 | 원본 항목과 결과 목록 비교 |

**합의한 결정**
오프라인 전용, 이름 검색, UTF-8, 빈 검색 시 전체 목록 표시는 사용자가 명시한 합의다. 각 결정의 별도 배경이나 이유는 제공되지 않았다.

**검증 방향**
CSV 읽기부터 검색 결과 표시까지 사용자에게 보이는 동작을 확인한다. 한글 이름이 포함된 UTF-8 데이터와 빈 검색어를 검증 사례에 포함한다. 테스트는 실행하지 않았다.

**가정·미결정**

- 인코딩 오류 처리: 중단, 대체 문자 사용 등의 정책이 정해지지 않았다. 오류 시 성공 기준도 결정 이후 확정한다.
- 이름 일치 방식, 이름 열 식별 방법, 공백만 있는 검색어의 취급, 검색 결과가 없을 때의 표시 방식은 제공된 합의에 없다.
- 추가 가정이나 모델 제안을 합의로 채택하지 않았다. 이 문서 작성은 추가 결정의 승인을 의미하지 않는다.

**실제로 읽은 스킬 파일**

- `.agents/skills/to-spec/SKILL.md`
- `.agents/skills/shared/PORTABILITY.md`

두 경로 모두 제공된 워크스페이스 기준이다.
