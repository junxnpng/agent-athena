## 이름·호출 구분

- 선언 이름 `omc-plan`의 실제 폴더는 `skills/plan/`이다.
- `project-session-manager`에는 `psm` 별칭이 있다.
- `omc-reference`는 `user-invocable: false`인 내부 참조용 스킬이다.
- 문서에 남은 `ralph-init`, `note`, `omc-help` 등은 현재 로컬 `SKILL.md`가 없어 이 목록에서 제외했다.
- `team`은 Claude 세션 안의 네이티브 팀, `omc-teams`는 tmux 기반 CLI 작업자 운영이다.

## Codex·Claude 사용 범위

- OMC는 Claude Code 중심의 오케스트레이션 플러그인이다.
- `ask`, `ccg`, `omc-teams` 등은 Codex·Gemini를 외부 CLI 작업자나 자문 대상으로 연결한다. 이것이 모든 OMC 스킬의 Codex 네이티브 실행을 의미하지는 않는다.
- 이 로컬 스킬 디렉터리에는 `agents/openai.yaml`이 없다.
- 여러 스킬이 OMC CLI·상태 관리·Claude 팀·tmux에 의존하므로 Markdown 복사만으로 같은 기능을 제공한다고 볼 수 없다.

## agent-athena와의 관계

- Athena의 현재 28개 스킬과 정확히 같은 이름은 없다.
- 반복 실행·검증·계획·메모리 등의 역할은 일부 겹친다.
- Athena에 도입하려면 고정 커밋 감사와 I7 검토가 필요하다. 자체 스킬 생성·상태 파일 관리·병렬 쓰기 등은 Athena의 규칙과 별도로 대조해야 한다.
