# Grilling

[deep-interview](../deep-interview/SKILL.md)를 읽고 적용한다. 현재 주장에 반례를 대거나 불필요한 제약을 줄이는 질문에 초점을 둔다. 의사결정 의존관계와 이미 합의된 답을 유지한다. 별도 인터뷰 상태나 질문 절차를 만들지 않는다.
