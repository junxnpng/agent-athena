# Claude handoff — 호환 이름

[handoff](../handoff/SKILL.md)를 읽고 실행 인계 절차를 적용한다. 이 이름은 원본 호환용이며 Claude CLI가 필수라는 뜻이 아니다. 명시적인 이 스킬 호출은 새 에이전트 인계 의도로 해석하되, 실제 시작은 현재 도구·정책·허용 범위 안에서만 한다. 사용할 수 없으면 문서와 수동 재개 문장을 제공한다.
