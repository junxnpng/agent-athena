# Writing shape — 글감에서 논지로

먼저 [공통 실행 계약](../shared/PORTABILITY.md)을 읽는다. 글감 전체를 읽고 원본은 읽기 전용으로 보존한다. 출력은 다른 파일이어야 한다. 기존 글과 요청된 저장 경로를 확인하고 경로가 정해지지 않았으면 한 번 묻는다.

독자가 이미 아는 개념과 글 안에서 처음 설명해야 할 개념을 구분한다. 사용자에게 이미 받은 독자·목적 정보를 다시 묻지 않는다. 서로 다른 논지나 각도를 가진 시작 부분 두세 가지를 제안한다.

기본은 함께 쓰기다. 선택된 시작 부분만 저장하고, 이어서 독자에게 필요한 다음 단락이나 블록을 제안한다. 사용자가 전체 초안의 자율 작성을 요청했다면 도입부 선택부터 직접 판단하고, 매 블록마다 선택을 요구하지 않고 그 범위에서 초안을 완성한다.

## 각 블록의 역할

선택한 시작이 약속한 논지를 유지한다. 다음 블록이 아직 설명하지 않은 개념에 의존하면 그 개념부터 소개한다. 글감은 그대로 이어 붙이는 대본이 아니라 나누고 합치고 바꿔 쓸 재료다. 필요한 사례나 근거가 없으면 빈틈을 밝히고 자료 요청 또는 해당 부분 축소를 제안한다. 경험이나 출처를 만들어 채우지 않는다.

형식은 역할에 맞춘다. 논증은 산문, 병렬 항목은 목록, 같은 속성 비교는 표, 원문 표현이 핵심이면 인용을 쓴다. 중요한 형식 선택의 이유를 간단히 설명하되 매 문장마다 토론을 강제하지 않는다.

합의한 블록을 저장하기 전에 출력 파일을 다시 읽는다. 사용자 편집을 보존하고 요청한 부분만 수정한다. 원본 글감과 출력이 같은 파일 또는 같은 실체를 가리키면 쓰지 말고 별도 출력 경로를 정한다.

끝으로 전환·반복·개념 소개 순서·출처를 확인한다. 공동 집필은 사용자가 마무리할 때, 전체 초안 요청은 요청한 범위를 완성했을 때 결과를 제공한다. 게시와 플랫폼별 배포는 별도 요청이다.
