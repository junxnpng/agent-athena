# .out-of-scope — 거절 기록

v0 범위 밖으로 결정한 것을 **파일 하나씩** 남긴다. 지우지 않는다 — 같은 요청이 다시 올 때 "왜 안 했는지"와 "언제 다시 볼지"가 여기에 있다.

파일 형식 (4항목 고정):

- **요청** — 무엇을 해 달라는 것이었나
- **이유** — 왜 지금 안 하는가
- **탈출구** — 그 필요가 생기면 무엇으로 대신하나 / 무엇이 바뀌면 재검토하나
- **과거 요청** — 날짜 · 맥락. 반복되면 여기에 줄이 늘어난다

새 항목은 이 형식을 그대로 복사한다. 요청이 반복되면 새 파일을 만들지 말고 **과거 요청**에 줄을 추가한다. 세 번 이상 반복되면 spec 재검토 후보다.
