# 쓰기 작업 병렬화

- **요청** — 여러 작업을 동시에 돌려 밤 처리량을 올리기
- **이유** — 반박 기반 수렴 게이트가 없으면 병렬 쓰기는 충돌과 조용한 덮어쓰기를 만든다 (spec §5 금지 사항, 근거 등급 C). 검증기 하나가 트리 하나를 판정하는 모델에서 트리가 둘이면 판정이 없다
- **탈출구** — 읽기 전용 작업(조사·분석)은 병렬 후보. 쓰기 병렬은 (1) worktree 분리 (2) 작업별 검증 (3) 병합 게이트 세 가지가 갖춰진 뒤 재검토
- **과거 요청** — 2026-08-27 · spec v0 §5, §12
