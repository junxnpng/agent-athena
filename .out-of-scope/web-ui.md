- **요청** — 밤샘 진행 상황과 결과를 보는 웹 대시보드
- **이유** — 밤샘은 headless다. 보는 사람이 없는 시간에 화면을 만들 이유가 없고, 아침 산출물은 `SUMMARY.md` 하나면 5분 안에 파악된다 (spec §7)

- **과거 요청** — 2026-08-27 · spec v0 §12에서 범위 밖으로 확정
